## Notational conventions

- Primal: $\text{Max } z = cx$ s.t. $Ax \le b,\, x \ge 0$ (or the Min/$\ge$ mirror).
- Dual variables are always $y$; primal decision variables are always $x$.
- $A^T$ denotes the transpose of the technological-coefficient matrix.
