# 05 — Quant Developer Timeline

> Semester-by-semester milestones from now (Year 3 Sem 2) to graduation and the first role.

---

## Now — Sem 2, Year 3 (Aug–Nov 2026)

**Study:**
- Mathematics for Machine Learning (Deisenroth) — core Tier 1 reading, targeted at the ML payoff
- ISLR (James et al.) — maps directly onto Applied Analytics coursework; deepens what's in the vault already
- C++ intro: *A Tour of C++* (Stroustrup) — one chapter per week, no pressure to be fast

**Build:**
- P1 (backtesting engine) — v1: a working event loop with one strategy and basic P&L tracking
- P2 (data pipeline) — v1: download and store OHLCV for 10 instruments into SQLite/TimescaleDB

**Competitive programming:**
- LeetCode: 3 per week (neetcode roadmap, Easy → Medium)
- Green Book: 2 probability puzzles per week

**Milestones by end of semester:**
- [ ] Backtesting engine running at least one live strategy with real historical data
- [ ] Data pipeline storing clean data for at least 10 instruments
- [ ] 30+ LeetCode problems completed
- [ ] C++ tutorial finished (at least through classes, templates, and move semantics)

---

## Sem 3 / Year 4 Sem 1 (Jan–Apr 2027, estimated)

**Study:**
- *Fluent Python* (Ramalho) — idiomatic production Python
- CLRS — focus on Chapters 1–16 (sorting, data structures, dynamic programming, graph algorithms)
- *Operating Systems: Three Easy Pieces* — OS fundamentals for systems interviews
- *Effective Modern C++* (Meyers) — C++ idioms that matter in production

**Build:**
- P1 v2: add proper transaction cost modelling, slippage, and a performance report module
- P3 (options pricing library) — pairs with Derivatives / Financial Calculus coursework
- P4 (order book simulator) — good systems design interview talking point

**Competitive programming:**
- LeetCode: 5 per week (moving into Hard, revisiting weak areas)
- Green Book + *Heard on the Street*: 5 problems per week

**Milestones by end of semester:**
- [ ] Options pricing library completed with docs
- [ ] Order book simulator completed and benchmarked
- [ ] 100+ LeetCode problems completed
- [ ] First mock interview session (Pramp or peer)
- [ ] C++ order book rewrite underway (or completed)

---

## Final semester / pre-graduation (May–Aug 2027, estimated)

**Study:**
- *Designing Data-Intensive Applications* (Kleppmann) — systems design interviews
- *C++ Concurrency in Action* (Williams) — concurrency for the latency-sensitive track
- Revisit weak areas from mock interviews

**Build:**
- P6 (C++ rewrite of P1 hot path) — the "I optimised X" story
- P7 (strategy platform API) — shows architecture thinking, not just coding
- Polish GitHub: clean READMEs, test suites, CI pipelines on all projects

**Job applications:**
- Applications open 3 months before target start date
- Target list: Goldman Sachs Strats (most accessible first role), bank quant tech, then hedge fund dev roles
- Internship applications for the summer before final sem are the priority if available

**Milestones before graduation:**
- [ ] 200+ LeetCode problems completed (with at least 30 Hard)
- [ ] 6+ full mock interviews done
- [ ] 3+ production-quality projects on GitHub
- [ ] At least one job application sent

---

## 1–3 years post-graduation

- Deepen C++ in production — this is where real proficiency happens
- Move into systems design and architecture ownership
- Build the market microstructure intuition that makes a QD irreplaceable
- Reassess path: pure engineering vs. moving closer to the trading side (many QDs shift to hybrid roles)
