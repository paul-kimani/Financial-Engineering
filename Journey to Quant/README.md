# Journey to Quant

> Three paths. One mathematical foundation. This folder is the operational roadmap — *what to study, what to build, and what to do* — sitting on top of the [[../Quant Roadmap - Reading List|reading list]] which covers *what to read*.

The quant world splits into three distinct roles that hire differently, test differently, and reward different strengths. This folder has a dedicated sub-section for each, so you can commit to one path or run them in parallel and compare.

---

## Paths

| Path | Core skill | Typical employer | Key interview filter |
|---|---|---|---|
| [[Quant Developer/README\|Quant Developer]] | Software engineering at speed | HFT firms, prop desks, prime brokerage tech | Competitive programming + CS fundamentals |
| [[Quant Researcher/README\|Quant Researcher]] | Statistical rigour + academic depth | Hedge funds, asset managers, research desks | Math/stats derivations + original research |
| [[Systematic Trader/README\|Systematic Trader]] | Strategy development + risk management | Prop trading firms, pod-based hedge funds | P&L intuition + backtesting methodology |

The paths overlap significantly in Tier 1–3 of the reading list (math, programming, ML) — that core is shared. The divergence is in depth of CS (highest for dev), depth of pure maths (highest for researcher), and depth of markets/risk intuition (highest for trader).

## How to use this

1. Read `00 — Quant Landscape & Roles` first to orient yourself.
2. Open the README for the path that pulls hardest — or all three in parallel if you're undecided.
3. Each path folder has the same five chapters (Career Map → Skills Matrix → Projects → Interview Prep → Timeline) plus a `Working Notes.md` for live reflection.
4. The path timelines converge on the same graduation date — use whichever suits where you are in the year.

The folder is designed to be grown: add dated entries to each `Working Notes.md`, tick off projects as you complete them, and update the skills matrix when a level shifts.
